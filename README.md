一个几百 KB 的上传包解压出来把磁盘写满了，清理脚本还在照常跑：清单只读第一层条目，嵌套包内层不计入；解压后大小取条目声明值，不再校验实际值；比率判定用加法而不是比值，炸弹可过；总量预算判定用严格小于，恰好等于预算被拒；嵌套深度只统计一层，深层嵌套漏检；路径校验只查是否以斜杠开头，盘符形式放过；路径校验不规范化相对段，穿越绕过；计划生成不校验条目数与文件名长度，海量小文件拖死；策略校验不检查是否设置比率上限；批量检查复用条目清单，后一个包命中前一个包的清单。arc/_impl.py 是核心，tests/test_limits.py 15个红。要修的是：按上面的顺序把 10 个缺陷逐个修掉。

运行方式
在仓库根目录执行：
pytest tests -q
初始状态下 arc/_impl.py 的 8 个桩全部抛出 NotImplementedError，因此预期恰好为 15 failed，且没有 collection error、import error、syntax error 或 test error。输出尾部应为 15 failed。实现完成后应为 15 passed。
